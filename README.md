# Shop Application

E-commerce application built with React and TypeScript.

## Features

- Product catalog
- Shopping cart
- User authentication
- Order management
- Admin panel

## Technologies

- React
- TypeScript
- Vite
- React Router
- Zustand (State Management)
- React Query
- Tailwind CSS

## Getting Started

```bash
# Install dependencies
cd client
npm install

# Start development server
npm run dev
```
